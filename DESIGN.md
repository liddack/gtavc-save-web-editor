# Save Workshop

The approved product flow is import, inspect, edit by area, review, export. This is a functional tool rather than a marketing site. Players work deliberately at a desktop in varied ambient light; use a light paper surface with a distinct neutral navigation rail and system fonts for sustained reading, while respecting system dark preference.

Restrained palette: tinted neutral surfaces, deep ink text and a muted magenta accent on selected navigation and primary actions. OKLCH colors. System sans for forms, system monospace for binary facts. Wide content area, compact native controls and ruled sections instead of nested cards. On narrow screens the sidebar becomes a horizontal navigation strip. No game assets or remote resources.

The confirmed implementation brief determines the structure; no additional visual exploration or bitmap assets are required for this technical implementation. All validation statuses and limitations are visible in the interface. Initial release is a preview pending manual game verification.
